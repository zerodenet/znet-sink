# 固定日志选择的脱敏复制与系统导出

日志页的单条、最新错误及当前已加载筛选结果先调用 `log_export_preview`。请求仅包含实际 ID/时间、来源/级别、可选时间边界、是否已搜索和是否仍有未加载历史；搜索原词和原正文不离开页面。搜索命中的集合以打开面板时固定的可见 ID 为准，不在宿主另一个呈现模型上重跑搜索，也不因新日志扩大集合。

宿主主窗口及 `diagnostic.export` capability 准入后，从实际私有 JSONL 取回这些 ID，逐项核对时间、来源/级别及时间边界。最多2000条，拒绝空、重复、过期身份或不合法过滤；每条历史记录解码最多2MiB，超大/损坏记录不能回填为请求方正文。UI已加载但记录不再可读时，要求刷新选择，保留原列表。

公共日志行复用 `diagnostics::log` 的 v3封闭宿主事件投影。只有来源匹配的分类可重建固定安全文案；其他行保留 ID、时间、来源和级别，明确省略原始正文、任意字段及未分类消息。未知marker、guest内容、自由错误、数字字段、搜索原文不能获得安全正文资格。文件明确是跨实例的有界历史，不能据当前页面解释为当前 VPN/远端健康。

准备后的字节复用既有 `DiagnosticExports`，最多四份、五分钟、总文件2MiB、用途绑定（日志与普通诊断不能互相消费）、单次交付。计划在预览开始固定 ClientScope 及独立客户端 scope generation；配置提交或实例变化推进 generation，即使 A→B→A 回到相同内容身份也拒绝旧计划。普通测速/观测使快照 revision 更新但不推进 generation，不误判失效；此 generation 不是远端内核 revision。交付前后核对原 generation，系统 IO 期间变化时保留“结果未确认”，不自动重放。`log_export_deliver` 只收原计划ID与copy/save/share枚举，不接收正文；复制在宿主clipboard capability内完成，保存/分享复用 `PreparedExport::RedactedDiagnostic` 与真实系统回执。消耗原计划后，失败、取消或结果未知不自动重放；需要新操作必须重新预览，筛选与列表保留。UI预览明确安全文案/省略数量及部分历史范围。

旧的普通日志/IPC剪贴板序列化器只输出类型校验的元数据和固定省略原因，不信任UI对象中的分类。IPC页面可继续查看已有详情；复制按钮及回执明确不交付payload或错误正文，安全遥测仍通过宿主诊断快照导出。

系统分享被接受不等于接收方保存；Linux测试和浏览器mock不证明手机系统文件提供者或剪贴板设备验收。原生文档适配不可用时，系统保存/分享禁用并解释，宿主脱敏复制独立可用。

验证包括固定ID/时间/来源/级别/时间边界、空/重复/2000上限、真实JSONL读取与源不匹配、原始秘密canary/伪marker、后来新增记录不进入原快照、用途/过期/单次交付与scope换代、2MiB拒绝，以及320px实际日志页面的保存取消、未知回执、失效scope、分享接受和44px控件。
