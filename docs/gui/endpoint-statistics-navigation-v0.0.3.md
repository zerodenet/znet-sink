# 端点进入共用统计页

端点详情和更多菜单复用应用共享的 TrafficWorkspace。移动端将固定来源与返回续接
保存在原底栏的二级路由；桌面端保留端点面板，切换同一工作区的统计视图。
返回后恢复原协议/观测详情模式，底栏不增加项目。

## 资源定位与计量

- 来源固定 profile、endpoint ID、协议、core instance、config revision、endpoint
  generation，以及客户端 scopeGeneration。客户端代次缺失、不安全或未确认时拒绝定位，
  并显示原因；它不是 Zero 远端原子前置条件。
- 共用页面只从实际统计目录选择身份匹配的行，不创建 scope，不回退到全局，不按显示名
  匹配其他对象。旧式端点仅可使用唯一已声明的实际入站或出站角色，并明确不是端点总计。
- 仅展示实际声明指标的平面；原浏览平面不可用时解释所选平面。各平面独立，数值不相加。
  统计 u64 保持十进制字符串；端点 number 身份继续现有安全整数准入，不强制转换不安全值。
- 用户可明确离开原定位并浏览其他范围；这会清除原定位的清空选择。

## 返回、失效与清空

返回前重新读取宿主身份、真实端点目录，再读取宿主身份。配置切换、A→B→A 代次变化、
对象删除或 generation 替换都会拒绝恢复旧详情。晚到读取不得覆盖用户随后打开的详情，
卸载或隐藏的来源页也不能恢复弹窗。系统/浏览器返回先关闭统计 Portal，再返回来源。
已经进入`data-state=closed`的Portal即使退出动画仍可见，也不再消费下一次返回。

端点来源的清空确认固定原统计计划，在提交前通过相同的宿主与目录读取再次核对原来源。
失败、变化或结果晚到时不重选目标，也不提交旧计划；实际清空仍使用既有统计权限、
epoch/generation 与内核前置条件。读取前后核对不提供新的远端原子保证。

隐藏的端点与统计页面保留界面状态，但不继续端点轮询、不改写当前统计浏览偏好；
共享事件通道与身份失效监听继续由应用拥有。

Peer 可达性或系统 VPN 验收。
