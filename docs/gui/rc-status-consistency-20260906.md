## 本次内容

- 修复内核正常运行时，概览因缺少状态变化事件而持续提示“运行状态待确认”的问题。可见窗口定时刷新状态，隐藏时暂停，操作期间让位于命令确认，旧查询不能覆盖新结果。
- 已确认由客户端托管的运行内核，在观察数据过期时保留重启入口；外部内核和忙碌操作仍受保护。
- 在已确认的专业概览与现有简约界面上统一状态、速率、支持能力、操作忙碌和失败反馈。代理模式与配置来源在失败或未确认时保留实际选中值。
- 切换简约/专业模式仅改变展示，不再自动补开 TUN 或系统代理。简约电源显式执行组合开关；单一路径开启或保留 TUN 恢复意图时，可关闭现有接管并取消恢复。
- 切换界面不重置会话流量，累计流量分别标明“本次会话”和“内核累计”；快速切换的界面偏好按顺序保存。
- DNS 的“关闭”改称“系统 DNS”，说明 TUN 可以独立运行、DNS 劫持依赖 Zero DNS，以及应用设置时 TUN 重建可能造成的短暂中断。

实现与复核记录：[状态刷新与 DNS 依赖](./overview-status-freshness-20260906.md)、[简约与专业模式一致性](./cross-mode-consistency-20260906.md)。本轮完成共享状态和交互修正，不把这些结果视为全部视觉设计已经统一的证明。
