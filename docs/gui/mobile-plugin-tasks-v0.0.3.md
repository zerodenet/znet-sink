# 移动插件前台任务与结果恢复

本批复用共享 `plugins/scheduler`，接入原生 profile 核对后的前台 owner。不是 VPN 服务，
不持有 TUN，也不交付系统后台调度。iOS Release 的外部插件执行限制保持不变。

## 执行与暂停

原生设备/ABI/代次核对完成后唤醒单一 Rust worker；重复 Ready/Resumed 不创建多个队列。
后台立即封闭原 executor 并唤醒 owner，停止发起剩余排队目标；在途 SDK 可能继续排空，
不能声称撤回网络请求。恢复后只在新的原生代次检查到期意图，不复活旧页面或旧执行。
没有 JavaScript 定时器，也不因 UI 切换底栏取消任务。

`tasks.schedule` 在可执行的移动前台宿主中允许保存 5 分钟至 7 天的周期意图。每30秒的
宿主前台检查只是最早发起机会，长任务、暂停和系统终止均可推迟；`nextRunUnixMs` 不承诺
实际执行时间。后台不运行这条前台轮询。平台状态与页面明确显示 `foreground-only` 及
“后台执行尚未适配”；不会注册一个空 OS Worker 来冒充后台能力。

每次保存生成新的意图 revision。排队固定原审阅、安装 generation、原生代次和本次
attempt ID；dispatch、状态写入和最终回写均核对原对象。单组件 busy、VM/SDK 预算、
权限、系统隔离限制继续生效。共享调度发布检查现在位于临时文件刷盘后、正式 persist
之前，等待 IO 的旧调用不能靠之前的检查写入。要求进程隔离的组件仍不开放。

## 有界持久记录

每个任务仅保留一个 `lastAttempt`，继续受256项/256KiB注册表预算约束，不承诺无限历史。
SDK Rust/TypeScript 提供只读类型；旧记录缺少该字段表示未提供历史，不推断从未执行。
新记录的时间均为十进制字符串，缺失完成时间保持 `null`。

| 阶段 | 已知事实 | 恢复行为 |
| --- | --- | --- |
| queued | 原目标已排队，未通过持久 dispatch 标记 | 原 owner/授权/代次失效时记 cancelled；保留后续周期意图 |
| running | 已保存 dispatch 准备标记，可能已进入 VM 或外部 SDK | 原 owner/授权/代次失效记 unconfirmed，不能推断副作用没发生 |
| completed | 原作用域的 VM 结果和状态更新已接受，完成记录已发布 | 下一周期可按原意图重新核验 |
| failed | 插件正常返回 `ok:false`，明确请求后续重试 | 保留既有有界退避；不是宿主猜测超时结果 |
| cancelled | 旧排队工作未发出 | 取消时间以观察记录表示，不编造执行完成时间 |
| unconfirmed | dispatch 后缺少可交付回执或持久完成确认 | 不自动换号/重放或继续该任务的新周期 |

`dispatchAtUnixMs` 是准备跨 VM 边界的持久时间，不证明 VM 已执行成功。
`completedAtUnixMs` 仅在已接受结果时提供，`observedAtUnixMs` 是状态核对时间，不能当成
实际结束时间。进程恢复不保存租约，不能凭记录重新授予能力。组件被停用/撤权或任务删除、
替换后，旧完成不能修改新任务的计数、时间或状态；原在途结果仍可能成为历史日志。

scheduled invocation 的 payload 增加只读 `attemptId`，与 `taskId` 一起固定于原排队对象，
便于插件关联自己的外部幂等键或查询。该编号不是权限凭据。宿主不负责猜测业务是否成功；
插件必须先核对外部结果。明确重新保存任务会创建新意图并清除旧 lastAttempt，不等于确认
或撤回旧副作用。宿主不会为缺回执自动执行这一步。

## 验证与缺口

真实原授权 lease、隔离文件系统和进程 owner 重建测试验证：锁后/发布前撤权、旧授权
重授、同值替换、实际包重装、无重复 dispatch、队列 owner 引用退役、未知屏障、明确完成
与失败、原生代次暂停/恢复、损坏记录拒绝和字符串时间 DTO。原生代次测试是 Rust 模型
测试，不替代手机回调运行。窄屏 UI 只验证限制信息与原管理入口，不模拟任务成功。

实际平台、工具链与逐提交结果记录于[验证账本](../verification/mobile-client-v0.0.3.md)。
API24完整 Rust host check 不证明 Android Rust/JNI/guest 全链；iOS完整App/VM/前后台
检查不自动计为任务执行验收。Galaxy S8、iPhone、锁屏、低内存、OS后台唤醒、系统调度
恢复及完整任务管理页仍须分别实施/验收；不能称完整 A19/A21 已完成。
