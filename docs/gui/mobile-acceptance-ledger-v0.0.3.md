# v0.0.3 移动适配验收账本

交付为 develop 基线 `fd198ba52711f018334860b8a6704546ccd349fd` 上的单个 draft PR #46。版本保持 `0.0.3-dev.202610131010`，没有发布、合并或签名。PRD V3 是验收目标；下列客户端实现和构建证据不等于全部 A/E 项完成。

## 本轮可审阅实现

- 固定四底栏、概览唯一顶部统计入口、二级页面返回、草稿保护、系统返回与移动触控布局；移动投影保留管理入口。
- 全部策略组、selector 直接成员与自动组语义、组/节点测速、停止排队并 draining、配置/实例失效检查。
- 配置/订阅两个分段，路由为二级入口；普通配置删除的替代/停止预览、CAS 与未知结果记录；端点恢复来源覆盖和真实 Packet API。
- Android SAF、固定宿主材料保存/分享和 UIKit 文档适配器；设置迁移的白名单、原生 Zero schema 校验、范围预览和 CAS。不迁移秘密、系统授权、插件授权、非默认新通知/发行偏好。
- 捕获实际 IPC 记录，时长 1–300 秒、总存储 1–10 MiB，宿主持有预算；队列、入盘失败、scope 换代、停止及清理 barrier 分开反馈。固定最多 2 MiB 的脱敏诊断快照，四份计划/五分钟期限/单次交付，未知结果不重放。
- 完成连接历史的当前筛选、最多 2000 条/2 MiB 固定快照导出；只保留经过类型和语法验证的公共连接事实。活动连接也通过实际 pinned IPC 和 `zero-api` 快照固定原筛选/实例/配置，权限在真实查询服务验证；系统交付前重新核对身份，未知结果不重放。
- 捕获恢复账本最多32项/64KiB，仅持久元数据；进程重建将未完成会话标为中断/结果未知，不恢复执行。损坏账本阻止新捕获，明确清理只删除捕获材料及其账本。
- 原生 Ready/Resumed 到期核对复用订阅执行器，每ID互斥、持久未知屏障、有限发起预算；普通订阅真实200/304条件同步、私有validator缓存和显式按源CAS清理已接入；系统后台调度仍未适配。
- 共享 Rust 控制桥及实际 IPC 只读诊断核对，确认真实实例/revision与单次回执；监听取消不关闭共享连接，显式处理有界广播缺口。原生服务/扩展注册及其事件采集尚未完成。
- Host interface 实际 DTO、发现、事件与 Host 采样时钟映射，只显示真实支持指标；Host 无 reset 准入。没有增加虚构宿主采样器。
- 内核和客户端两个版本入口读取真实公开发行目录、渠道、说明，目录错误与权威空结果分开。内核随应用维护；未验收渠道不开放安装。自动检查与订阅周期显示保存意图，没有冒充系统调度。
- 可选通知偏好与系统权限状态分开；查看/保存不请求授权，显式请求后重新读取，呈现结果仍未确认。关于展示实际版本、作者与 MPL 文本及构建生成的可搜索依赖许可材料。

- 后续增加普通订阅未知结果的固定来源只读核对；真实 IPC 身份可读不证明原提交成功，缺少候选及持久回执时仍禁止解除屏障。
- 后续增加普通活动配置的有限本地恢复：原候选及真实 confirmed 回执持久记录后，仅在来源、材料、组合与运行身份仍匹配时完成 SQLite 关系和应用设置投影。五阶段屏障保留至本地完成，不重新下载或 apply；需要外部系统代理重定位的更新继续原有链路，未获得本批本地恢复准入。
- 后续增加宿主有界 QuickJS worker、原授权 lease 及排队/执行时限分离；签名插件页面固定材料与 review/channel，后台、撤权、更新使旧调用失效。当前仅完善客户端通用/桌面边界，未开放原生移动插件能力或宣称进程隔离。
- 后续补齐DNS/TUN/运行网络/测速四设置表单的明确草稿放弃与提交中离开保护；来源刷新不覆盖脏草稿，保存失败保留输入。工具页恢复的完成任务只作历史，当前活动结果按实际客户端范围/代次恢复；清理后查询固定原范围，不由历史重开触发。
- 日志单条及固定筛选复制/系统保存分享、IPC元数据复制、桌面旧诊断导出统一收口到宿主安全投影或明确元数据省略。日志/诊断计划绑定客户端scopeGeneration，A→B→A也不能复用旧计划；系统IO已发出后变化保留未确认，不自动重放。

## 构建与验证记录原则

全量 Rust fmt/workspace all-target check/all-features tests/clippy、前端验证、浏览器 Chromium/WebKit 和原生 SDK 构建由同一 PR 的最终 commit CI 记录。无签名 Android APK、UIKit 无签名 Simulator library、纯共享 Rust target check、主宿主 Rust check、真实手机验收分别报告。依赖目录区分 resolved/build input/compiled/最终 APK 包含；缺资料保持缺口。

详细设计及边界见 [移动平台](mobile-platform-v0.0.3.md)、[有界诊断](bounded-mobile-diagnostics-v0.0.3.md)、[实际构建依赖许可](dependency-license-inventory-v0.0.3.md)。未运行项不会用旧 commit 的成功或界面测试替代。

本轮具体边界：[活动连接导出](active-connection-export-v0.0.3.md)、[控制桥](runtime-bridge-v0.0.3.md)、[原生前台订阅](mobile-subscription-foreground-v0.0.3.md)。

具体嵌入生命周期见 [RuntimeOwner](embedded-mobile-runtime-v0.0.3.md)：没有 zero-ffi 依赖，没有改变桌面子进程/API 架构；Android 完整 Proxy 编译实际失败于固定 core 的 TUN opaque return type（CORE-05）。iOS owner SDK 检查本轮未运行；CI该检查仅保留手动入口，不能计为通过。

用户已将原生运行装配后置；目前独立Proxy owner只保留已验证的组件，不接入服务或C FFI。普通订阅提供固定来源版本及实际运行身份的只读核对，并限定恢复已持久confirmed回执后的本地发布；旧记录缺少候选/持久回执或作用域漂移时仍未知，元数据重置不解除该屏障。移动owner未接入时不提供运行核对及恢复准入。订阅用量缺失或越界显示未知；只有完整来源计数才计算比例，额度采样时间没有提供时明确标注。

插件及订阅后续边界见 [宿主有界执行](mobile-plugin-execution-boundary-v0.0.3.md)、[签名页面与 SDK 原租约](plugin-page-channel-v0.0.3.md)、[普通订阅只读核对](ordinary-subscription-reconciliation-v0.0.3.md)。插件通道预算、CSP 解析顺序及 VM 未接入系统文件选择的限制均有实际回归；这些通用客户端边界不开放 Android/iOS 插件执行。
