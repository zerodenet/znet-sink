# 配置工作区：本地保存与来源保护

普通工作区属于客户端配置领域，使用现有 Zero schema、组合链和 SQLite 持久化。
它不新增手机配置方言，也不以本地保存代替运行配置或 VPN 确认。

## 材料及来源

snapshot 先核对来源归属。插件托管、受保护或没有普通正文的来源只返回元资料及原因，
不返回来源、覆盖、最终配置正文；普通编辑入口不能据此取得写权限。plan、validate、
save 和 apply 再核对当前来源，旧面板不能绕过变化后的归属。

普通来源以 JSON 文本传给 Rust；Rust 生成来源、覆盖及合成视图文本。浏览器解析只作
语法和对象根值检查，其结果不参与提交或格式化；u64 最大值不经过 JavaScript number
往返。Rust 使用实际 `RuntimeConfig::parse` 校验 schema、结构及引用，保存原 Value，
不把 typed schema 重新序列化为一份删减配置。格式化也由 Rust 完成。

原生校验错误保留实际错误类别对应的父字段及可用行列，缺少精确路径时使用根位置，
不猜测字段。通用消息不回显配置、凭据或任意 parser 原文。本地 schema 通过不代表
运行内核已编译相同协议，运行兼容性仍须真实预检。

## 纯本地提交

本地保存固定完整来源和关系图、AppConfig、规则集摘要及客户端 scopeGeneration。
SQLite 发布时按一致锁序核对这些条件，并在同一代次 fence 内完成本地持久化及内存
发布；失败恢复仅针对本操作仍持有的关系，不能覆盖后来的修改。

保存保留当前本地代理运行归属，不 retarget、不 apply、不重建 TUN，也不为返回回执
查询 IPC。成功回执是“已保存，待应用”；重开本地材料仍不能生成一份运行确认。
只读合成视图在未确认时是本地候选，不能称作已提交的运行配置。

## 草稿、预检及原操作

外部更新或配置/实例变化保留脏输入，使旧预检失效并说明冲突。明确放弃后才刷新正文；
晚到的读取、校验、保存或操作回执只属于原编辑版本，不能覆盖新输入或新来源。

运行预检固定来源、客户端覆盖、规则、合成候选、实际运行身份及期限。应用只接受原
plan ID，未知结果只核对该 ID 的回执，不能用旧的相同 digest 回执确认新操作，也不能
重新生成计划来重放原请求。真实运行确认与本地发布是两个阶段；部分成功分别记录。
捕获参数也保存完整冻结Value，重新解析后须在副作用前逐值匹配，不能在改变TUN后
才用摘要发现范围变化。提交与TUN协调固定原物理连接，并在第一次副作用及配置命令前核对原实例/revision；
只从实际确认的配置回执推进预期revision，不从后来的运行快照采纳新基线。保持现有
TUN能力租约、15秒命令响应预算、DNS释放和Windows宿主依赖准备。仅路由变更的快速
路径同样核对实际已启用TUN与冻结参数，并在配置回执后重新读取，不能把本地参数
直接冒充实际设备。纯本地冻结参数不匹配会明确拒绝并允许重新预检；已发送命令或
晚到身份变化的未知屏障保留。工作区没有取得
原运行配置材料的权威快照时，失败不自动把本地旧材料apply回去或重建旧TUN；旧的
通用调用补偿行为保持独立。客户端核对不新增 Zero 远端 config
命令的原子前置条件，相关 CORE-03 边界仍保留。

当前操作与未知屏障在宿主进程内；换页或重新加载可找到原ID，进程重启持久恢复及
自动补完本地发布尚未实现。真实运行已确认而本地CAS失败时，保留原回执并明确
`runtime_confirmed_pending_local`，不能声称全部成功或覆盖新来源。

## 工作区重启仍需适配

工作区保留需要重启的影响和具体不可用原因。本批不再调用“先写来源，重启失败后
无条件整表恢复”的旧链路；内核管理中的普通重启仍是独立操作。

现有启动流程使用非秘密 bootstrap，再从当前 state 组合并 runtime-only apply；
它没有向工作区返回冻结材料的启动回执，watchdog 也重新读取当前材料。固定版本内核
另明确拒绝 live apply 修改 `api.control` 和 `runtime.principal_quota_state_path`。因此不能把
普通重启之后的热应用当作这些启动字段已经生效。

后续客户端工作包括冻结启动材料、局部 launch snapshot、真实 PID/readiness、运行
回执、本地 CAS 及 watchdog 窗口。普通来源的受限安全启动材料通道尚未实现和验收；
若受保护材料或具体平台确需通用 core 接口，再单独协调，不能将所有重启归为 core 阻塞。
当前提供明确本地保存路径，不将缺回执降级为导出临时配置兜底。
