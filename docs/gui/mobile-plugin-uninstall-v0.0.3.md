# 插件卸载的固定预览与逐项结果

2026-10-15，基线 `c216a77ce9b19a31c9f6633b14f76ee66cd38213`，同一 Draft PR #46 → develop。
本批范围是宿主卸载管理，不扩展移动插件 SDK、VPN、core 或 native 装配。

## 资源与确认边界

卸载由主应用宿主页发起。预览固定已验证安装材料、发布者、组件与资源集合；
名称、插件自行提供的路径、ID 前缀和后来的目录行都不能授予删除权限。
用户确认的是打开预览时的原集合，不随后台新增资源扩大。
确认前重新核对安装、配置关系、文件历史、宿主和作用域；变化后要求重新预览。
计划五分钟有效，删除资源最多 128 项；资源收集器的材料预算为 16 MiB。
最近记录最多 16 条，未完成记录不得通过容量淘汰解除原操作屏障。

| 对象 | 归属与行为 |
| --- | --- |
| 已安装包与组件 | 按签名材料及发布者身份核对；同 ID 新安装不接受旧计划 |
| 托管订阅与关联配置 | 核对 provider/remote namespace、真实关系与组件归属；共享、冲突或无法检查的材料阻止删除 |
| 托管规则集 | 归属和实际引用共同准入；不按名称或 ID 前缀扩大范围 |
| 配置、授权、状态与缓存 | 仅清理原计划内的插件隔离对象，不删除其他发布者或插件的数据 |
| 根 vault.key | 共享主密钥，保留 |
| 已发布 ZRS 与包 blob | 区分刻意保留、共享、待清理或无法确认；登记消失不代表磁盘全部清理 |

当前选中的插件配置阻止卸载，展示真实替代关系及原因。用户须先在现有配置入口
明确选择有效替代，再重新预览；没有替代时可先添加普通配置。单纯断开 VPN 不会清除
当前配置选择；本入口尚不执行停止并取消配置选择，也不自动选择首个剩余配置或声称已切换。
受保护、共享或无法证明全部相关引用的范围也明确阻止。未在使用且通过归属与引用检查的
资源才进入本地卸载执行；运行态、平台 VPN 与远端健康不是本地删除的附带成功承诺。
待删托管配置本身也须是可检查的 Zero JSON；缺正文或未知来源格式不会当成无依赖。
携带内嵌正文的订阅来源 URL 只作 provenance，不作为读取或删除外部文件的权限。
已安装但因隔离能力不足而没有运行授权的包仍可按实际安装登记卸载；缺少授权不生成
“组件已删除”回执，其签名定义由真实包登记回执覆盖。存在但已退役或材料不匹配的授权行
仍阻止本入口，须先处理身份冲突；不能把它当成缺行继续执行。

## 原操作与恢复

预览、确认和执行是不同动作。确认使用固定计划及客户端预生成的原操作 ID，
执行前保存原目标，逐项记录实际执行及持久回执。重复点击不扩大资源或创建并行删除。
退出面板不撤回已经提交的操作，也不依赖网页定时器继续清理。

界面分别呈现可核对完成、仍残留、结果未知、需要手动处理，以及刻意保留的对象。
目录没有行或文件暂时不存在不等于原操作已完成；没有原回执的未知删除不自动重放，
也不通过新操作 ID 或重新安装绕过原屏障。后继材料不被旧操作删除。

独立卸载记录入口允许包登记消失或宿主重开后找到原操作。核对只读原操作的持久逐项回执，
不重新扫描当前物理资源，也不推进清理阶段；“剩余”是原操作记录，不能据此证明对象当前仍存在。
失败后保留已完成项与剩余项，不推断旧调用一定没有执行，不能显示泛化的
“全部已卸载”回执。秘密、配置正文、订阅 token 和内部文件路径不进入普通错误或预览。

同一插件的执行、SDK 与调度沿用原安装代次，并持有跨宿主活动租约；卸载取得独占租约，
无法取得时拒绝，不等待旧调用后把它当作已取消。相同包重新安装也产生新代次，旧回调不能
借新登记继续写入。根目录与隔离目录逐层拒绝符号链接或重解析点；逐项回执绑定原操作和资源。
文件、SQLite 与安装登记按阶段提交并保留故障证据，不宣称跨存储原子事务。
版本与历史检查约束合作写入者，不提供对恶意回滚全部本地材料的防护保证。
安装登记增加代次与墓碑字段；读取旧登记时使用明确的兼容默认，随后写入新格式。
旧客户端可能拒绝新字段，不能把此存储变化当成已验证的直接降级流程。
