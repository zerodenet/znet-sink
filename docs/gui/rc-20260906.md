## 本次内容

- 配套内核修复关闭内置 DNS 时的 TUN 系统解析出口；客户端增加 DNS、TUN 和配置保存的协调事务与健康确认。
- 配置及模式切换确认实例和配置版本后再提交，应用失败不再隐式重启。重启保持 TUN 意图，修改代理端口同步实际监听和已开启的系统代理。
- 订阅缺失规则集、无法转换的路由规则明确失败，避免静默删除规则。Clash 的未支持规则类型、额外参数（包括 no-resolve）、错误目标或非末尾 MATCH 会拒绝导入，兼容范围见 [订阅管理](./subscriptions.md)。
- 客户端更新操作互斥，清理过期候选，区分检查失败与已是最新；安装完成但重启失败时只重试重启。
- 诊断凭据字段脱敏补齐；失去活跃事务的内核升级记录阻止误启动。

应同时安装本轮客户端和内核；客户端安装包不内嵌本轮内核。旧内核 `0.0.16-rc.202609050728` 没有这次系统 DNS 出口修复。
