# 有界 Flow 选择关闭与原操作核对

本页记录 PRD V3 A18 的客户端关闭边界。Flow 与 Packet 路径是两个不同控制面；此流程不改变端点启用意图，不清理连接历史、日志或统计，也不启用配置或 VPN。

## 宿主接口与明确选择

五个 `gui_flow_close_*` 命令仅供主宿主窗口使用，继续接受客户端交互模式与真实内核权限检查：

| 接口 | 输入与输出 | 副作用边界 |
| --- | --- | --- |
| `inventory` | 返回宿主签发的 `inventoryId`、真实实例与配置版本、客户端代次、采样时间及 canonical targets | 只读活动快照，建立有期限的宿主选择材料，不关闭连接 |
| `preview` | 输入原 `inventoryId` 与固定的 `{flowId,targetKey}` 集合；返回原集合的 `planId`、到期时间与逐项目标状态 | 只读核对原目标，不扩大为后续连接，也不提交关闭 |
| `submit` | 输入原 `planId`，返回逐项回执与计数 | 每个计划只接受一次提交；不把重复请求改成新操作 |
| `status` | 输入原 `planId`，返回该计划的宿主阶段及已有回执 | 纯读取原记录，不查询新目录来推断关闭，也不补发命令 |
| `discard` | 输入尚未提交的原 inventory 或 plan ID | 释放未提交的选择材料；已提交计划不能借关闭页面撤销或清除 |

页面使用单独的宿主 canonical 目标选择器，初始不勾选任何对象。旧活动事件行、暂停快照、历史记录及其相同 `flowId` 不继承关闭资格；打开选择器后，用户明确选择本次真实目录中的对象。不得将旧页面 ID 静默映射到新实例里的同名对象。

`targetKey` 绑定公共 `zero-api::FlowSnapshot.record` 的连接身份事实，包括 ID、开始时间、网络、入站、来源和目标。后续目标详情须仍符合原材料，不能仅凭 ID 相同视为同一对象。ID、时间、配置版本及代次使用十进制字符串传输，不经 JavaScript 不安全整数往返；可缺失的原字段不由界面编造。

## 运行身份、通道与权限

入口必须已有 `SubscriptionOwner.current()` 的观察租约，没有租约时不猜默认 socket、pipe 或 AppConfig 端点。宿主捕获当前 profile/client scope、客户端代次、宿主进程会话和观察租约代次，再在该观察绑定上取得一个 `BoundControl`。目录、详情、身份核对与关闭均沿用这个原物理连接，不在提交中发现或重连到另一端点。

真实运行身份包含原内核提供的非空字符串 `core_instance_id` 和显式配置 revision。客户端数字 scope 只是另一个本地前置条件，不能替代内核真实实例身份。能力准入要求兼容的控制面与实例、Flow 观测契约；capabilities 的 permissions 元数据不是自行授予权限，实际认证通道仍逐请求执行 Read/Control 检查。

目录读取、预览和每项提交在相应阶段核对原身份与本地租约。配置、客户端代次、观察租约或运行实例变化后，旧目标不恢复可执行资格。提交前失效表示未向替代对象发送关闭；提交进入网络阶段后身份核对中断则是结果未确认，不能据此重发。

此客户端链路不能提供内核尚未声明的原子保证：当前公共 `FlowCloseCommand` 只有 `flow_id`，没有远端 expected instance/revision CAS。原物理连接与客户端前后检查不等于能够排除另一控制器在检查与命令之间更新配置。本页不以客户端锁声称补足该远端能力。

原生 Android/iOS VPN/core 宿主装配仍未接入，此关闭服务对相应平台明确拒绝。桌面移动布局预览可使用既有桌面真实控制通道，不能由布局宽度推断原生运行支持。

## 回执与未知结果

| 逐项状态 | 证据与显示 |
| --- | --- |
| `closed` | 原命令明确 `accepted:true`，结果携带相同 `flow_id` 与 `closed:true`，且提交后原身份核对有效 |
| `ended` | 原目标的公共 Flow 详情明确 `Completed`；表示已结束，不计为本次关闭成功 |
| `rejected` | 明确拒绝，或原命令明确返回 `closed:false`；不计成功 |
| `unknown` | 请求进入提交后超时、断联、身份变化，或缺失/不兼容回执；只读保留原操作，不重放 |
| `stale` | 提交前目标或原运行绑定已失效，未向新对象提交 |
| `not_submitted` | 未获原控制资格、只读预检未完成或执行预算已耗尽，未发出该项关闭 |

缺少 `closed`、错误的目标 ID、未知 accepted 值、缺行、`not_found` 或新的活动列表中不再出现该对象，都不是 `closed` 的替代证据。部分成功与其他状态分项显示，不能以 Promise fulfilled、Toast 或隐藏连接行冒充成功。

提交前，宿主锁定所选目标以防重叠计划重复关闭。未知结果继续阻断相应实例与连接 ID；新目录、刷新、缺行及过期预览不会解除该屏障。`status` 读取已有原计划结果；界面不会将缺项、重复项或不匹配计划的回执转成成功，也不会通过重新预览自动重放未知目标。页面卸载不取消已进入宿主的操作，活动列表仍由原观察通道更新。

## 预算、保留与材料边界

- 目录最多展示 500 项，读取 501 项用于明确 `truncated`；截断不称为已选“全部内核连接”。目录响应另受 2 MiB 预算限制。
- 目录与未提交预览各最多四份，期限五分钟；计划与回执最多 32 份。旧已确认终态可回收，未知记录不会为腾出容量静默删除。
- 一次提交总执行预算 30 秒，每项最多五秒。预算耗尽后不再发出后续项，已发出的在途请求不能被界面声称撤回。
- 界面另外保留最多八次原操作回执投影，切换新目录后仍可打开原计划并只读核对。容量回收优先移除没有未知项的已确认回执；八次均有未知项时停止读取新的选择材料，不挤掉旧未知证据来继续操作。这不是另一份任务执行队列。
- 宿主只投影选择必需的 ID、目标、网络和时间；不把代理配置、订阅 URL/token、认证材料、原始核心错误或完整 Flow 正文写入新回执。目标等网络事实仍属用户数据，展示按纯文本处理。

这些目录、计划、未知屏障与回执属于当前宿主进程内存，尚不是跨进程持久执行日志。进程退出或异常重启后不能凭新目录恢复原操作的权威回执，也不承诺跨重启严格一次执行。自动重放不属于恢复策略；后续若补持久化，须另行绑定原宿主/运行身份、提交阶段和真实回执，不能仅保存 ID 后重发。

## 源码与验证范围

生产边界位于 `models/flow_close.rs`、`commands/flow_close.rs`、`services/flow_close.rs`，界面投影位于 `features/flow-close/` 与专用选择组件。测试应覆盖真实本地 IPC 的固定选择、明确关闭与完成、拒绝/缺失回执、实例与观察代次变化、原物理连接关闭后不重连、不安全或缺失身份拒绝、重叠计划与未知屏障、预算和逐项结果，以及页面原计划绑定、取消和重复点击。

源码与测试用例存在不代表已通过运行验收；本批实际执行结果以对应提交的验证记录和 CI 为准。此有限关闭流程不据此宣称 A18 的全部活动/历史连接、Packet、平台或真机验收完成。
