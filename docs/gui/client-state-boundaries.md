# 客户端存储、执行与定时边界

2026-09-12。本轮以客户端自身闭环为目标；插件场景用于检查能力是否足够，不替插件实现登录、通信协议、订阅业务或服务端密钥方案。

## 实际入口盘点

| 现有入口 | 管理者与持久化 | 本批调整 / 剩余 |
| --- | --- | --- |
| 配置、订阅保存 | app_database 的关系表和事务，domain_store 负责装载 | 保留已有模型；数据库 schema 1 → 2 增加普通能力存储表，不复制配置库 |
| 订阅自动同步 | AppState 去重，subscription 的定时循环与有限重试 | 重试/冷却快照通过共同存储能力持久化；周期内执行状态仍在内存 |
| 规则自动刷新 | AppState 去重，rule_set 的定时循环与有限重试 | 同上；与订阅共享重试时间计算，业务解析、应用流程保持各自归属 |
| 工具任务 | ToolRuntime 队列、并发配额、取消、历史容量 | 尚未迁移为持久任务；不能把重试快照称为任务恢复 |
| 节点测速 | client-core ProbeRuntime 与内核请求 | 仍需与共同任务归属/授权对齐；取消不能被描述成撤回内核执行 |
| 插件调用 | AppState capabilities 与受限 VM | 本批不增加插件数据库/定时 API，先由现有客户端调用验证存储服务 |

## 已实现：普通存储边界

- 复用 `znet-sink.db`、WAL 和已有连接加固，新增 `capability_values`；从 schema 1 原子升级为 2，旧关系表和元数据保留。旧客户端遇到 schema 2 会拒绝打开，不承诺直接降级。
- `storage.read/self`、`storage.write/self` 分别校验。命名空间由宿主签发的租约身份确定，API 不接收另一主体的 owner；数据库目录由可信客户端选择。未来外部适配器必须由宿主绑定稳定主体身份，不可接受 guest 指定身份或直接使用易随升级改变的代码摘要作持久归属。
- 不暴露 SQL、数据库句柄或路径。普通字节存储不是秘密/加密容器，禁止将受保护材料直接放入此表。
- 键最多 128 字节，值最多 64 KiB；单主体最多 256 条、1 MiB；全局最多 16384 条、64 MiB。额度计算包含键，全球额度还包含主体名；这些是逻辑数据配额，不承诺 SQLite/WAL 文件占用等于配额。
- 批量修改最多 32 项，在一个 IMMEDIATE 事务中检查归属、旧版本、额度和授权；任一项失败整批回滚。所有查询参数化。
- 创建必须不存在；替换、删除要求精确版本。版本由数据库单调时钟分配，删除重建也不会复用旧版本，防止旧请求覆盖新记录。
- 读出数据仍受租约结果预算、有效期及撤权控制；日志记录能力和结果，不记录值。提交后的撤权或回执失败不等于没有写入，调用方不得自动重放写操作。
- 尚无对外列表、插件卸载保留/清理、用户数据导出、秘密存储和大材料接口；不是完整插件存储 SDK。

## 已实现：现有定时刷新使用共同存储

订阅、规则各有可信主体与独立的 `retry-state`，不会读写彼此状态。内容只包含现有失败计数、下次重试时间和周期标记，没有 URL、账号或配置正文。快照带版本，未知版本或损坏不能静默重置。

启动恢复最近一次完整周期保存的快照；每轮刷新结束后以版本比较方式保存。读写失败或版本冲突暂停对应自动刷新并写客户端错误日志，保留手动功能。数据库 IO 在 blocking 任务执行，避免阻塞异步调度线程。

本批保留既有有限重试、冷却、成功手动刷新使重试失效、禁用/删除过滤和同资源去重规则。错过多个周期仍按已有逻辑合并为当前一次到期检查，不逐个追赶历史周期。应用退出后没有独立后台定时进程。

**这不是持久任务执行日志。** 进程在一轮执行期间崩溃，该轮尚未保存的变更可能丢失；下次到期检查仍可能重新执行原有同步。尚无跨进程抢占、执行前持久占位、结果不确定核对或严格一次执行保证，不据此开放有任意副作用的插件定时任务。

## 接下来的客户端闭环

1. 执行任务统一归属、授权检查、取消和终态；沿用 ToolRuntime/ProbeRuntime 的真实执行边界，明确已提交副作用与结果不确定。
2. 在现有任务服务上增加持久执行标记和恢复决策。崩溃后的任务标为中断/待核对；定时规则与执行实例分开，重新执行需检查当前权限及资源版本。
3. 增加用户可见的调度暂停、恢复及数据保留决策；确定卸载时哪些数据保留，谁有权清理，不能由插件删除其他主体数据。
4. 分离网络等待、CPU、材料及输出预算；继续接通统一配置/材料访问控制。普通存储不能冒充受保护存储。
5. 对内置入口完成这些验证后，再提供受限外部适配接口；外部声明定时不能取得独立授权，运行时仍须客户端检查。
