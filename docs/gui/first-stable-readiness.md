# 首个稳定版验收

当前结论：仍为候选版本。自动化回归与安装后的真实联网证据分别记录；前者通过不能代替后者。

后续跨入口核查与新增修复见 [客户端产品核查](./product-audit-20260905.md)。下文数值保留前轮验证快照。

## 本轮修复

- DNS 关闭、Real DNS、Fake-IP 的切换作为 DNS、运行中 TUN、配置落盘的共同事务。客户端控制的 TUN 先停止旧拦截，再应用 DNS，重新启动并核对健康状态和参数，最后保存；明确失败时恢复原配置。请求超时或实例、配置版本发生变化时停止竞争性回退并返回未确认状态。
- 内核独立保护系统 DNS 出口。关闭内置 DNS 时仍发现系统解析服务器并为自动路由准备绕行地址；开启 DNS 拦截仍要求配置 DNS。系统 DNS 发现失败且启用严格路由时，在接管前报错。
- 重启后的 TUN 恢复必须同时满足 enabled 和 healthy，避免显示恢复成功却无法联网。
- 启动、看门狗重启、再次升级遇到失去活跃事务的 pending 升级记录时明确失败，提供备份位置。只有当前进程内仍持有的升级事务允许启动未提交候选；不能凭相同 PID 认领旧事务。自动续回退尚未实现，仍是稳定版阻塞项。

DNS 切换会重建客户端控制的 TUN，期间可能短暂中断接管；本轮不声明切换无中断或切换期间无泄露。配置文件自主管理的 TUN 仍由内核配置事务协调。

## 必须完成的安装验收

平台：macOS Intel、macOS Apple Silicon、Windows x64、Linux x64。每个平台 35 项，共 140 项。

| 维度 | 覆盖 |
| --- | --- |
| DNS | 关闭、Real DNS、Fake-IP |
| 接管 | 关闭、系统代理、TUN、系统代理与 TUN 同开 |
| 网络 | IPv4、双栈 |
| 操作路径 | 首次安装与导入连接；配置和节点切换；DNS 在线切换；接管模式切换；重启恢复；内核升级成功与失败；客户端升级与中断；正常退出；强退恢复；无效配置及网络故障恢复；诊断与状态一致性 |

每个网络组合应记录：系统域名解析、TCP HTTPS、UDP 转发、节点域名解析、预期直连/代理路由、IPv4/IPv6 的成功或明确不可用状态、应用提示和实际参数一致性。关闭接管时验证系统网络保持正常；关闭 DNS 时应使用系统解析。需要域名规则的行为应按实际域名恢复能力核对，不能把 IP 连通视为域名规则生效。浏览器自带 DoH 不代表系统 DNS 验收通过。

生命周期证据需包含退出前后的受管 PID、端口、TUN 路由、系统代理；同时保留外部实例不受影响的断言。升级必须验证权限拒绝、安装失败、启动失败、恢复接管失败、替换文件前后强退，以及再次启动的恢复结果。每条证据注明安装包、配套内核摘要、系统版本、操作步骤、预期和实际结果，并去除订阅凭据及浏览记录。

## 发布门禁

机器记录：[release/stable-readiness.json](../../release/stable-readiness.json)。要求字段由 `scripts/stable-readiness.mjs` 固定，记录不能通过删平台或删用例缩小验收范围。

1. 完成代码和验证工具提交，执行 `node scripts/check-stable-readiness.mjs --fingerprint` 获取源代码指纹。
2. 用这一源代码构建配对候选，完成安装验收。填入内核 commit、各平台两个产物 SHA256，以及每项 passed、installed-e2e、HTTPS 证据地址、证据 SHA256、时间、测试者。清除已解决的 blockers；不支持或无法验证的承诺项不能直接标 passed。
3. 将指纹和验收记录单独提交。指纹覆盖完整 Git 源码树，只排除记录自身；任何代码、依赖、脚本或文档变化均需重新确认对应候选。
4. 在干净工作区运行 `pnpm verify:stable`。Bash、PowerShell 的 stable 发布入口会再次检查；GitHub stable tag 构建也检查发布提交父版本的证据，并限制发布提交只改版本元数据。RC/dev 不受这项稳定验收门禁阻断。

门禁检查证据完整性与版本绑定，不代替人工或受控 runner 对证据真实性的审核。测试产物摘要记录候选构建；发布产物仍需现有构建/签名流程。`pnpm verify:frontend` 包含门禁本身的回归测试。

本机真实特权 TUN、系统代理切换测试会影响正在使用的网络，因此本轮采用独立临时目录、loopback 和原始包管线测试。特权安装验收需要独立测试机器/虚拟机，尚未取得的证据保留 pending，不能据此发布 stable。
