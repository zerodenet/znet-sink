# ZNet Sink v0.0.1

首个统一编号的正式版，与 Zero Core、ZBoard 一起从 `v0.0.1` 开始发布。旧 Release 与 tag 已按项目所有者要求清理。

支持 Windows x86_64、macOS Intel、macOS Apple Silicon 和 Linux x86_64。提供节点与订阅管理、系统代理与 TUN 模式、DNS 配置、状态诊断、内核更新，以及手动 TUN 清理恢复入口。安装包与更新清单通过既有构建、自动化测试和签名流程生成。

## 本次安装验收豁免

项目所有者于 2026-09-08 明确批准仅对本次 `v0.0.1` 豁免四个平台的安装运行验收。构建、自动化测试、更新签名与产物完整性检查继续执行；本次豁免不表示以下场景已经通过实际安装验收。

以下范围在 Windows x86_64、macOS Intel、macOS Apple Silicon、Linux x86_64 均尚未完成安装验收：

- DNS 关闭、真实 DNS、Fake-IP 与代理关闭、系统代理、TUN、系统代理加 TUN 的组合，以及各组合的 IPv4 / 双栈联网。
- 首次安装、导入与连接，配置和节点切换，DNS 与流量接管模式切换，重启恢复。
- 内核升级成功与失败、客户端升级及中断恢复。
- 正常退出清理、强制退出恢复、无效配置和断网恢复，以及诊断信息与实际系统状态的一致性。
- 配置和订阅跨资源恢复在存储失败、系统代理失败及进程中断下的故障注入验证。

上述验收记录保留为待完成，后续正式版本继续适用正常安装验收门禁。

## 从旧编号版本切换

旧 `0.0.16` 等版本的编号高于新 `0.0.1`，不会出现常规自动升级提示。请先备份应用配置、关闭系统代理与 TUN，再下载对应平台安装包手动安装；也可在版本管理中明确选择此签名版本执行降级。版本编号重置不代表旧数据的降级兼容性已通过验收。
